# pagos

Alcance: Comprometido (§3.2).

Reporte y confirmación del pago de administración.

## Qué va aquí

- El residente reporta un pago y adjunta el comprobante
- Administración lo confirma

## Con qué se conecta

- Backend: `Admind_Backend/apps/pagos/`
- `apps/documentos/`: el comprobante

## Referencias

Maestro §3.2, §3.4
