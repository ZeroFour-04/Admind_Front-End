# unidades

Alcance: Núcleo (§3.1).

Las viviendas del conjunto y sus vínculos.

## Qué va aquí

- Listado de unidades
- Vínculos de cada unidad: propietario o arrendatario, si reside, desde cuándo
- Cierre de un vínculo, que no lo borra

## Con qué se conecta

- Backend: `Admind_Backend/apps/unidades/`
- `apps/personas/`: la persona que se vincula
- `templates/componentes/`: `Tabla`
