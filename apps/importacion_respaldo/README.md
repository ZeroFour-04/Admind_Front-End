# importacion_respaldo

Alcance: Comprometido (§3.2).

Carga masiva y respaldo.

## Qué va aquí

- Subir un archivo CSV o Excel y ver el resultado de la importación, fila por fila
- Generar un respaldo

## Con qué se conecta

- Backend: `Admind_Backend/apps/importacion_respaldo/`

## Referencias

Maestro §3.2, §5.11
