# reglas

Alcance: Núcleo (§3.1).

Configuración de las reglas beta del conjunto.

## Qué va aquí

- Formularios por tipo de regla (parámetros, área, vigencia). No hay editor de texto libre: el catálogo es de tipos parametrizados
- Mensaje de rechazo que lista **todas** las reglas que fallaron

## Con qué se conecta

- Backend: `Admind_Backend/apps/reglas/`
- `apps/conjuntos/`: es un paso del asistente de creación
- `apps/reservas/`: donde el residente ve el resultado de la validación
